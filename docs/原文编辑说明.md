# 原文编辑与字体

在「编辑原文」中可按对象类型筛选文字、矢量和图片。编辑单个文字对象时，离开输入区域或按 `Ctrl+Enter` 提交。原文对象和文字行默认勾选更换为可嵌入的本机字体，可按需取消。

字体文件来自本机；使用和嵌入受字体条款约束。可编辑对象取决于 PDF 的文字层、字体和内部结构。图片图章和手写签名是可视标记，证书签名需要独立的数字签名流程。

在「编辑原文 → 提取或剪切特征」可沿自由曲线圈出轮廓，闭合后复制或剪切。片段保留轮廓内的纸底，可移动、缩放、旋转 90° 和换色。保存为 `.jvp` 后可再次调整片段。[特征编辑指南](0.15.0-分屏查找与图纸编辑.md#提取或剪切图纸特征)

操作见 [页面局部擦除与文字编辑](0.14.1-局部擦除与文字编辑.md) 和 [快速开始](QUICK_START.zh-CN.md)。
