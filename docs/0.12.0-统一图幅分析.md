# 0.12.0 统一图幅参与差异分析

日期：2026-11-17。适用于数据库导出、打印来源不同，页面标称尺寸不一致，但图纸位置和相对边距基本一致的 PDF。最终发布与安装状态见 [验证记录](VALIDATION.zh-CN.md)。

## 使用方法

1. 主界面打开“对比”，选择 A、B PDF。
2. “分析尺寸”默认选择 **按统一图幅（推荐）**。A 为参考，B 等比例适配到 A 的页面范围并居中，然后执行差异分析。
3. 如仍有整体位移，使用自动平移配准或两点对齐，再分析。统一图幅与平移配准使用同一坐标系。
4. 检查高亮、差异详情和文字辅助。PNG / CSV 导出包含所用模式；多页对比沿用当前模式，逐组按对应 A 页适配。
5. 需要把整体打印比例或纸张尺寸变化也作为差异时，切到 **按原始尺寸**。模式切换清空偏移、忽略区与未完成的对齐点，旧结果会标为过期，需重新分析后导出。

“各自适应窗口”仅控制并排视口的显示。上方“分析尺寸”决定实际分析是否统一大小；取消视口适配不会悄悄切换分析方式。

## 如何统一

设两页可见边界为 `Aw × Ah` 与 `Bw × Bh`，B 的等比倍率为 `k = min(Aw / Bw, Ah / Bh)`，初始位置为 `((Aw − k·Bw)/2, (Ah − k·Bh)/2)`，再叠加用户的手动平移。使用 PDFium 给出的可见方向和页面边界，包含原页面旋转及 CropBox。

例如 A 为 600×800 点，B 为 1200×1600 点，内容也同比放大：B 以 0.5 倍进入分析。相同图形可重合，而新增细点、孔位或文字变化仍参与完整像素差分。这不修改两份源文件。

当两页长宽比不同，保留 B 的比例并居中留白，不分别拉伸横轴与纵轴。覆盖不同仍会提示。统一图幅不自动识别图框、裁去不同边距、旋转扫描倾斜或恢复已经被源 PDF 裁掉的内容；这些情况需要单独处理。

## 精度与报告

- 并排高亮、叠加、拉幕、闪烁、忽略区、局部预览、瓦片分析、自动平移的粗/精细阶段，以及多页预算均使用相同的 B 变换。
- DPI 仍控制分析采样密度；统一图幅时按 A 页的参考坐标取样。不同打印器、字体、抗锯齿或非整数像素缩放仍可能产生残余差异，不保证任意 PDF 都能零像素重合。
- B 的偏移显示为“参考 mm”。它是 A 页坐标的换算单位，不能据此判断纸张或机械零件的真实毫米尺寸。
- 统一图幅会把整体出图比例变化归一化，这符合跨数据库导出图纸对比的需求；若比例变化本身需要检查，使用“按原始尺寸”。两种模式均不是 CAD 尺寸语义或制造合格判定。
- 统一图幅的单页 CSV / PNG 标明模式、B 的缩放和参考单位。批量清单记录每组所用模式与倍率；同批不同页面可以采用不同倍率。旧原始尺寸模式保留既有报告坐标含义。
- 从批量清单进入单页时恢复该组自己的模式，防止查看旧结果时混用新的分析尺寸。模式也参与缓存与结果有效性判断。

本次不新增依赖、在线服务、OCR、字体或外部素材。原创代码继续 MIT OR Apache-2.0，既有第三方许可、精确源码补充、外部资源阻断及原图只读边界保留。主编辑器和其他 PDF 功能不参与对比模块的图幅变换。
