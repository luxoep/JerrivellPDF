# 0.14.1 发布验证范围

本机 Windows 完整发布门禁已通过，覆盖 33 组前端检查、84 项 Rust 测试以及最终构建后 10 组原生联动。检查包含 Windows 依赖许可、生产构建、NSIS 打包及产物校验值。

额外浏览器核验覆盖 24 个中英文导航场景，以及 100% 和 125% 显示缩放下的局部擦除交互。原生专项验证包括重叠选区、旋转后重复擦除、保留 3400 像素图片，以及导出重开后的文字和矢量。

| 核验项 | 核验范围 |
| --- | --- |
| 页面局部擦除 | 多个选区、撤销、保存与重开、保留顶层文字与矢量、保留选区外图片清晰度 |
| 文字与字体 | 新增文字自动应用、原文单对象提交、默认更换为本机字体和可手动取消 |
| 紧凑导航 | 常用窗口宽度、中文和英文、顶部操作可达及文档切换 |
| 原生回归 | PDF 打开、图章片段、图像编辑、原文编辑、可编辑项目、图纸对比和文档处理 |
| 许可与归档 | Windows 依赖许可策略、安装包与附件校验值、公开源码中的原创合成 PDF |

安装包、源码归档、第三方对应源码与 SHA-256 校验值见 [0.14.1 Release](https://github.com/luxoep/JerrivellPDF/releases/tag/v0.14.1)。
