# 0.15.0 发布验证范围

本机 Windows 完整发布门禁已通过，覆盖 33 组前端检查、87 项 Rust 测试以及最终构建后 10 组原生联动。检查包含 Windows 依赖许可、生产构建、NSIS 打包及产物校验值。

实际浏览器验证了左右与上下分屏、独立视图状态、搜索高亮与定位，以及自由曲线从绘制到提交的操作。另在本机用实际图纸验证剪切、换色、旋转和导出。`.jvp` 在全新进程重开后，页面预览逐像素一致，片段可再次换色、移动、缩放、旋转和保存。原 PDF 的 SHA-256 保持一致。

| 核验项 | 核验范围 |
| --- | --- |
| 分屏 | 两种布局、切换编辑目标、各窗格独立的页码、滚动和缩放状态 |
| 查找 | 查找可检索正文、定位命中、高亮随缩放与旋转对齐 |
| 签名 | 制作方式、本机模板、日期时间与 UTC 偏移 |
| 局部编辑 | 曲线分段绘制、手动闭合、提取、剪切、换色、旋转、移动、缩放与擦除 |
| 可编辑项目 | 保存、全新进程重开、继续编辑、再次保存和 PDF 导出。超出资源上限时保留已有项目 |
| 公开归档 | 源码归档、安装包、指南、第三方源码与 SHA-256 |

安装包、源码归档、第三方对应源码与 SHA-256 校验值见 [0.15.0 Release](https://github.com/luxoep/JerrivellPDF/releases/tag/v0.15.0)。
