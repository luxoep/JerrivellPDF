# 0.13.0 发布验证范围

发布者在本机 Windows 环境通过前端检查、82 项 Rust 测试、18 个对比界面场景，并用最终构建的可执行文件通过 10 组原生回归。NSIS 安装包完成构建并核对 SHA-256。测试范围为本机可执行文件和合成样本，未覆盖从安装包重新安装、GitHub Actions 或实体打印机组合。

| 核验项 | 覆盖内容 |
| --- | --- |
| 复核项目 | 双语备注保存、同一进程重算及重开复核、匹配差异恢复、定位下一处待复核差异 |
| 来源校验 | 源文件改名或移动后重选相同内容；拒绝同名不同内容；打开失败时保留当前复核 |
| 对比回归 | 图幅归一、缩放及对齐、多页分析、局部差异与细点、批量与单对报告、取消、保护独立工作区 |
| PDF 回归 | PDF 打开、图章片段、图像编辑、原文编辑、可编辑项目和文档处理的原生流程 |

测试使用原创合成样本。公开源码中的 PDF 为仓库的两个原创样本。安装包校验值、源码归档与第三方对应源码见 [0.13.0 Release](https://github.com/luxoep/JerrivellPDF/releases/tag/v0.13.0)。
