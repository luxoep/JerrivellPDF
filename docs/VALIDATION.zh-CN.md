# Jerrivell PDF 0.15.0 发布验证

[English](VALIDATION.md)

本记录对应 Windows x64 的 [v0.15.0 发布](https://github.com/luxoep/JerrivellPDF/releases/tag/v0.15.0)，适用于该标签和安装包。发布后 `main` 上的文档可以继续更新。

本机 Windows 发布检查通过 **33 组前端检查、87 项 Rust 测试和 10 组原生联动**。检查同时覆盖 Windows 依赖许可、生产构建、NSIS 打包和产物校验值。以上为本机测试结果。复现命令见[构建说明](BUILDING.zh-CN.md)。

## 核验范围

| 核验项 | 检查内容 |
| --- | --- |
| 分屏 | 左右与上下布局、切换编辑目标，以及各窗格独立的页码、滚动和缩放状态。 |
| 查找 | 可检索文字的搜索与定位，高亮随缩放与旋转对齐。 |
| 签名 | 制作签名、保存本机模板，以及放置时记录本机日期、时间和 UTC 偏移。 |
| 局部编辑 | 分段绘制曲线、手动闭合、提取与剪切、换色、旋转、移动、缩放和擦除。 |
| 可编辑项目 | 保存 `.jvp`、全新进程重开、继续编辑、再次保存和导出 PDF。保存超出资源上限时保留已有项目。 |
| 公开归档 | 源码归档、安装包、指南、第三方对应源码和 SHA-256。 |

额外浏览器验证覆盖分屏、搜索定位及完整的曲线选区交互。本机还用一份图纸验证了剪切、换色、旋转和导出。`.jvp` 在全新进程重开后，页面预览逐像素一致，片段仍可编辑和保存。原 PDF 测试前后的 SHA-256 一致。公开源码归档中的 PDF 样本均为原创合成样本。

验证记录覆盖上述工作流。其他 PDF 结构、Windows 环境和打印机驱动的兼容性需分别核对。查找需要 PDF 含可检索文字。[下载安装包、源码、指南、第三方对应源码和校验文件](https://github.com/luxoep/JerrivellPDF/releases/tag/v0.15.0)
