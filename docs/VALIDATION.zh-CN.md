# 0.12.0 发布验证范围

发布者在本机 Windows 环境完成 33 组前端、80 项 Rust、17 个对比 React 场景，以及构建后/安装后各 10 组原生流程；另有原有 5 组独立 PDF 输出检查和新旧报告检查。这不是 GitHub Actions，也不是任意文档、系统、打印机的准确性认证。

原创合成图纸同比改变页面尺寸，在统一图幅的 150/300/600 DPI 下均得到零变化像素；受控细点仍保留4像素差异。旋转、CropBox、逐页倍率、扫描图片、对齐和取消均有覆盖。所有公开附带PDF仅为两个原创样本；不公开用户文档或本机原始测试输出。安装包与源码校验值见同版Release。
