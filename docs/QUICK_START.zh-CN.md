# Jerrivell PDF 快速开始

[English](QUICK_START.md) · [首页](../README.md)

适用于 Windows x64 上的 Jerrivell PDF 0.15.0。安装完成后，文档在本机处理。

## 安装或升级

1. 从 GitHub 下载 Windows x64 安装包，在发布页对照 `SHA256SUMS.txt` 核对 SHA-256。[0.15.0 安装包](https://github.com/luxoep/JerrivellPDF/releases/download/v0.15.0/Jerrivell.PDF_0.15.0_x64-setup.exe) · [全部版本](https://github.com/luxoep/JerrivellPDF/releases)
2. 如有需要，单独安装 Microsoft Edge WebView2 Evergreen Runtime（x64）。离线电脑可提前取得微软独立安装程序，再传到目标电脑安装。[WebView2 下载](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
3. 运行 Jerrivell PDF 安装包，再从开始菜单打开 **Jerrivell PDF**。在其他电脑上使用完整安装包，以取得匹配的 PDFium 和许可文件。

升级前先保存已打开的项目并退出应用。通过「设置 → 设置为默认 PDF 应用」选择 `.pdf` 的系统关联。如果资源管理器入口缺失，使用「设置 → 修复打开方式入口」。在 Windows「设置 → 应用」中可卸载。

## 打开、阅读与查找

- 点击「打开」或按 `Ctrl+O`，在独立选项卡中打开 PDF 或 `.jvp`。再次打开同一文件会切回已有选项卡。也可用资源管理器中的「打开方式」、PDF 右键命令或「发送到」打开 PDF。
- 打开两份 PDF 后，用选项卡右侧的「左右分屏」或「上下分屏」。各窗格保留独立的页码、滚动位置和缩放。点击窗格即可切换编辑目标。
- 按 `Ctrl+F` 查找文字并高亮，点击结果可跳到对应位置。PDF 允许复制时，「选字」可复制已有文字层。纯扫描图像和轮廓字需要 OCR 才能变为可检索文字。OCR 单独规划。
- `Ctrl+滚轮` 缩放，普通滚轮连续阅读，也可选择「适宽」或「整页」。按 `Ctrl+W` 关闭当前选项卡。

## 整理和保存页面

拖动左侧缩略图调整页序。使用页面工具旋转、删除、复制页面或插入空白页。「添加 PDF」把其他来源的页面添加到当前文档。「工具」提供图片转 PDF、批量拆分、页码、水印和页面裁剪。

| 要保留的内容 | 操作 |
| --- | --- |
| 源 PDF、页序、新增文字、标记及片段等可编辑内容 | 用「保存项目」或 `Ctrl+Shift+S` 保存 `.jvp`。再次打开项目即可继续编辑。 |
| 阅读或分发用的 PDF | 用「保存副本」或 `Ctrl+S` 打开导出预检。检查页序和提示后保存。新增对象可能以可见内容写入。 |
| 一组图纸页对的复核进度 | 用「保存对比项目」保存 `.jvcmp`。一并保留 A、B 两份 PDF，方便下次核验。 |

0.15.0 采用手动保存。自动恢复在后续路线中规划。[路线图](ROADMAP.zh-CN.md)

## 编辑、标记与签名

- 用「添加内容」插入文字、图片和图章。添加文字时，可在页面拉出文字框并直接输入。「标记」可添加高亮、形状、线条和箭头。
- 使用「编辑原文」或「文字行」处理受支持的原有文字和对象。可调整的范围取决于原文档的字体和内部结构。
- 在「添加内容 → 签名」中手写、键入姓名或导入签名图片，也可保存为本机模板供复用。放置时显示本机日期、时间和 UTC 偏移，由设备时钟记录。证书签名属于单独的操作流程。
- 在「编辑原文 → 提取或剪切特征」勾画轮廓。选择「自由曲线（手动闭合）」，画完后点「闭合曲线」。「复制为片段」会保留原位置的内容，「剪切为片段」会用白底覆盖原位置。片段可移动、调整大小、以 90° 为单位旋转或换色，轮廓内的纸底和笔迹保持不透明。
- 使用「标记 → 页面局部擦除」裁掉选区内图片和受支持的嵌套内容的显示。要修补单张图片时，可使用图像橡皮擦。局部擦除和剪切后的 PDF 仍可能保留底层数据，分享时应按含有原始数据处理。

## 对比图纸和继续复核

1. 打开「对比」，将旧版 PDF 设为 A、新版设为 B，并选择页码。对比从磁盘读取文件，需要比较尚未保存的编辑结果时，先保存 PDF 副本。
2. 选择「分析尺寸」。「按统一图幅（推荐）」将 B 等比例适配到 A，可能归一整体出图比例差异。需要检查整体出图比例时使用「按原始尺寸」。统一图幅的参考毫米是相对于 A 页的坐标，实际尺寸以原始图纸为准。
3. 核对对齐方式，选择 DPI 和像素容差。按需用「两点平移对齐」「自动平移配准」并确认，或手动调整偏移。再点击「开始对比」。
4. 检查差异列表和详情，标记已复核内容并填写备注，按需导出 PNG 或 CSV。「多页对比」支持分组复核与批量 CSV，失败或未配对页应单独检查。
5. 单击「保存对比项目」，将当前页对保存为 `.jvcmp`。下次使用「打开对比项目」恢复。若源文件移动，选择原文件或字节相同的副本。应用会核验来源并重新分析。[分析尺寸说明](0.12.0-统一图幅分析.md) · [图纸复核项目](0.13.0-图纸复核项目.md)

## 打印与排查

打开「打印」，预览后设置页码范围、纸张、方向、份数、颜色和 DPI。可打印区域和最终出纸效果由 Windows 打印机驱动决定。

| 现象 | 处理 |
| --- | --- |
| 窗口空白或缺少 WebView2 | 安装微软 x64 Evergreen Runtime 后重试。 |
| 提示缺少 PDFium | 使用完整的 Jerrivell PDF 安装包重新安装。 |
| 网页开发预览只能查看排版 | 使用 Windows 桌面版处理 PDF。开发时运行 Tauri 应用。 |
| 图纸对比出现大量差异 | 重新核对页对、分析尺寸、方向和对齐，再检查 DPI 和容差。 |
