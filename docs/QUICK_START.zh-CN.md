# Jerrivell PDF 快速开始

适用于 Windows x64 上的 Jerrivell PDF 0.15.0。

## 安装和升级

从 Release 下载并安装 0.15.0。[最新 Release](https://github.com/luxoep/JerrivellPDF/releases/latest) · [Jerrivell PDF 0.15.0 安装包](https://github.com/luxoep/JerrivellPDF/releases/download/v0.15.0/Jerrivell.PDF_0.15.0_x64-setup.exe)

需要旧版时可在 [全部 Jerrivell Releases](https://github.com/luxoep/JerrivellPDF/releases) 选择对应版本，使用前查看该版本发布说明与随包 LICENSE；旧归档不会自动采用当前版本的许可。

运行前需要 [Microsoft Edge WebView2 Evergreen Runtime（x64）](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。本安装包不附带 WebView2；离线电脑可在准备环境时取得微软的独立安装程序，再离线安装。

按向导安装后，从开始菜单启动 **Jerrivell PDF**。不用启动 PowerShell、Vite 或源码目录。不要只复制应用主 EXE 到另一台电脑；匹配的 PDFium 和法律资源也是运行所需文件。

升级时先保存 PDF 副本和可编辑项目，正常退出旧程序，再运行新安装包。系统 PDF 默认打开方式保留原设置；如需更改，可从应用“设置”进入 Windows 默认应用设置。卸载使用 Windows“设置 → 应用”。

## 打开与阅读

- 点击“打开”或按 `Ctrl+O`，在新选项卡打开 PDF。也可从系统打开方式或右键入口交给应用。
- 打开多份文件时使用顶部选项卡切换；重复打开同一路径会聚焦已有文档。
- 打开两份 PDF 后，使用选项卡右侧的「左右分屏」或「上下分屏」。各窗格独立保留页码、滚动位置和缩放，点击窗格即切换编辑目标。
- 按 `Ctrl+F` 查找可检索正文。命中处直接在页面高亮，点击结果可跳到对应位置。
- `Ctrl+滚轮` 缩放；普通滚轮连续阅读。“适宽”和“整页”调整视口，左侧栏可收起。
- 选择“选字”后拖动文字并复制。扫描图像、没有文字层或禁止复制的页面不能凭此得到文字；当前不提供 OCR。

## 整理页面

在左侧页面缩略图中选择页面，拖动调整顺序。复制页和空白页可直接从主界面操作；“工具”提供图片转 PDF、批量拆分、页码、水印和页面裁剪。使用“导入 PDF”把其他来源页面加入当前文档。

需要继续编辑文字、标记、签名或片段时，用「保存项目」或 `Ctrl+Shift+S` 保存 `.jvp`。导出前可检查预检结果，使用「保存副本」生成用于阅读和分发的 PDF。

## 添加、编辑和图章

添加文字时，可直接在页面上拉出文字框并输入；拖动边框调整排版范围，字号与文本框大小分别控制。标记工具提供高亮、形状、直线、折线箭头和引导线。

“编辑原文”和“文字行”用于可识别的原有 PDF 对象与文字。PDF 可能把文字拆成小对象、转为轮廓或只保留扫描图像，不能把原文编辑理解为所有 PDF 都能像普通文档一样重排。替换本机字体时，字体及其嵌入使用仍应遵守相应许可。

图章支持制作、导入和导出。从 PDF 制作片段时可选择多个区域，分别插入或在列表中管理。通过「编辑原文 → 提取或剪切特征」还可绘制自由曲线，手动闭合后复制或剪切特征，移动、旋转 90°、缩放或换色。[特征编辑指南](0.15.0-分屏查找与图纸编辑.md#提取或剪切图纸特征)

在「添加内容 → 签名」中可手写、键入姓名、导入签名图片或保存本机模板。放置签名时记录本机日期、时间和 UTC 偏移，显示在签名下方，供阅读时参考。

## 页面局部擦除

打开「标记 → 页面局部擦除」，在页面预览画出一个或多个区域，再点击「擦除选区」。自由曲线可以分段绘制，最后点击「闭合曲线」。擦除裁掉选区内图片和受支持的嵌套内容的显示，保留原始清晰度。可编辑的顶层文字和矢量仍可在「编辑原文」按对象处理。修复一张图片的底色时，从图片对象打开像素橡皮擦。[页面局部擦除与文字编辑](0.14.1-局部擦除与文字编辑.md)

## 图纸对比

1. 点击顶部“对比”，打开独立工作区，分别选择旧版 A 和新版 B。
2. “分析尺寸”默认 **按统一图幅（推荐）**，B 等比例适配到 A 后再实际分析。该模式适合页面标称尺寸不同、内容相对位置与边距基本一致的图纸。
3. 长宽比不同会保留比例并居中留白。若整体打印比例变化也需要检查，改为 **按原始尺寸**。模式切换会清空偏移及忽略区，并使旧分析结果过期。
4. 需要整体平移时，先使用“自动平移配准”审阅并确认可靠建议，或使用两点对齐/手动偏移。自动配准不可靠时需人工对齐。
5. 选择分析 DPI 和容差，点击“开始对比”。取消、失败或尚未完成时不能据此判定图纸相同。
6. 在差异列表中定位区域或细点；底部详情可拖动调高、展开并用 `Ctrl+滚轮` 查看。可逐项勾选“已人工复核”。
7. 导出 PNG 概览或 CSV 清单到认可的本地目录。报告也可能含敏感内容。

“各自适应窗口”只改变并排显示，不决定分析是否统一大小。统一图幅的“参考 mm”是 A 页坐标的换算，不能作为实际零件尺寸测量。文字与尺寸辅助只比较允许复制的可提取文字，仍需核对视觉差异。

多页资料使用“多页对比”：生成页码配对后可逐组调整。每组分别适配对应 A 页；结果明确列出失败与未配对页。点击成功项进入该组详细分析，导出批量 CSV 保存配对状态、参数和变化数量。

对比载入的是磁盘文件快照。主编辑器中尚未另存的修改不会自动加入比较；需要比较编辑结果时先保存副本。

### 保存复核项目

在对比工作区中填写复核备注、标记已复核差异，然后点击 **保存对比项目**。同一项目记录一个 A/B 页对。下次点击 **打开对比项目**，选中 .jvcmp 文件，等待源文件核验和差异重算。若源文件移动，按提示选择字节相同的原文件或副本。操作见 [图纸复核项目](0.13.0-图纸复核项目.md)。

## 打印

在“打印”中设置范围、纸张、方向、份数、彩色/黑白和自动/150/300/600 DPI，检查预览后再提交。实际纸张和出纸效果还取决于 Windows 打印机驱动、可打印区域和设备。高 DPI 会增加处理时间与内存用量。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 缺少 WebView2，窗口无法正常打开 | 安装微软官方 x64 Evergreen Runtime 后重试 |
| 提示 PDFium 缺失 | 重新安装完整安装包；不要从不明来源单独替换 DLL |
| 浏览器页面无法读写 PDF | 使用桌面安装版；网页开发预览不含 Tauri 原生命令 |
| 不能选择或编辑扫描文字 | 当前没有 OCR，先确认文件是否具有可提取文字层 |
| 对比差异很多 | 核对 A/B 页码、分析尺寸模式、方向、偏移、DPI 和容差；打印驱动、字体、不同边距和扫描噪声也会产生差异 |
| 图纸看起来相同但需要核实实际比例 | 使用“按原始尺寸”；统一图幅会归一整体出图比例变化 |

开发与自行构建见 [BUILDING.zh-CN.md](BUILDING.zh-CN.md)。
