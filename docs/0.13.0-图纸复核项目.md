# 图纸复核项目（0.13.0）

图纸对比工作区可以把当前页对的复核进度保存为 `.jvcmp`。下次打开项目会使用相同的两张图纸和分析参数重新计算，再恢复能匹配的复核状态和备注。

## 保存和继续复核

1. 在主窗口点击 **对比**。选择旧版 A、新版 B 和要比较的页码，设定分析尺寸、DPI、容差、对齐偏移和忽略区。
2. 完成分析后，从差异列表打开一项。确认差异后勾选 **已人工复核**，有需要时填写 **复核备注**。用 **下一处待复核** 在差异之间继续检查。
3. 点击 **保存对比项目**，选择本地目录和 `.jvcmp` 文件名。新增备注、改变复核状态或调整分析设置后，需要再次保存。
4. 下次进入对比工作区，点击 **打开对比项目**，选中已保存的 `.jvcmp`，等待重新分析。恢复时会优先定位到保存时仍未复核的差异；若当时停在一项已复核的差异，继续定位到后续待复核项。

复核状态只在源文件校验通过、重新分析的差异也能匹配时恢复。区域已变化或无法确认时，以重新分析的待复核结果为准。

## 源文件移动或更换

- **文件改名或移动**时，按提示重新选择原文件或字节相同的副本。项目会核验内容指纹，文件名和路径相同也不能代替内容核验。
- **图纸内容已更新**时，打开原项目需要原来的那一版图纸。用更新后的 PDF 开启新一轮对比并另存项目，避免把旧的复核结论用于新版本。
- **图纸需要密码**时，重新打开项目会按图纸提示输入。项目文件中只有本地文件引用、校验信息、参数和复核记录，未打包源 PDF 或密码。

项目文件包含路径和备注，也属于审图资料，请和源 PDF 一起保存在认可的本地目录。

## 当前保存范围

`.jvcmp` 保存当前 A/B 页对、分析尺寸、DPI、容差、平移、忽略区、选中的差异以及该页对的复核状态和备注。多页对比可逐项打开详情，为需要继续审阅的页对分别保存项目。批量任务结果继续通过批量 CSV 导出。

对比项目采用手动保存。主编辑窗口的 `.jvp` 继续用于保存 PDF 编辑工作，现有的 PNG 和 CSV 继续用于输出对比报告。图纸对比、项目读取和重新分析都在本机进行。关于统一图幅和参考坐标，见 [统一图幅分析](0.12.0-统一图幅分析.md)。
