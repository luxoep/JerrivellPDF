# Jerrivell PDF 0.15.0

## 分屏和查找

打开两份 PDF 后，选项卡条右侧可切换「左右分屏」或「上下分屏」。拖动中间分隔线调整大小。每个窗格独立保留页码、滚动位置和缩放。点击窗格后，共用的编辑、打印和保存操作作用于当前选中的文档。打开更多 PDF 时，可以通过窗格标题选择要查看的文档。

按 Ctrl+F 输入关键词，页面高亮可检索的命中位置。点击结果或按 Enter 可定位到当前结果的第一处命中。扫描图片和转成路径的轮廓字没有可检索正文。

## 签名和签署时间

打开「添加内容 → 签名」，手写、键入姓名或导入签名图片。也可以把签名保存为本机模板。每次放到页面时，签名下方显示当前设备的日期、时间和 UTC 偏移。项目重开后仍可移动签名，保留原来的时间。该时间来自本机时钟，属于可见的签署记录。

## 提取或剪切图纸特征

1. 打开「编辑原文 → 提取或剪切特征」。
2. 选择「自由曲线（手动闭合）」，按住鼠标绘制轮廓。松手后可以继续绘制，最后点「闭合曲线」或按 Enter。也可以选择矩形、椭圆、多边形或套索。
3. 「复制为片段」保留原位置并将片段放在旁边。「剪切为片段」用白色纸底覆盖原位置，并把片段放回该位置，拖动后即可看到移出的效果。原 PDF 文件保持原样。
4. 在「添加内容」选中片段，可拖动、调整尺寸、顺时针旋转 90°、更换笔迹颜色或恢复原色。轮廓内的纸底和笔迹保持不透明，轮廓外可以看到下方页面。片段也会加入「图章」中的片段列表，便于放到其他 PDF。

「标记 → 页面局部擦除」也支持先绘制自由曲线再手动闭合。它裁掉选区内的图片及受支持的嵌套绘制内容，保留可独立编辑的文字和矢量线条。剪切覆盖和局部擦除均为可见编辑，隐藏的源数据可能仍在导出文件中。

## 保存后继续编辑

用「保存项目」或 Ctrl+Shift+S 保存 `.jvp`，再打开该项目继续移动、旋转和重新为片段换色。普通 PDF 副本适合分发，输出时会将新增片段和签名写成视觉内容。只导出 PDF 时，未保存的可编辑结构仍会提示保存项目。

新版可以打开既有 `.jvp`，含可换色特征片段的项目使用新版项目结构。保存前会按重开时的同一标准检查资源规模，只有成功后才替换旧项目文件。
