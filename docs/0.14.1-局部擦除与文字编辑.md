# 页面局部擦除与文字编辑

## 直接圈选页面区域

打开「标记」工具栏，点击「页面局部擦除」。在预览中画出矩形或自由形状，可累积多个选区并核对位置。点击「擦除选区」后，回到工作区查看结果。误擦可撤销。

局部擦除让图片及受支持的嵌套绘制内容在选区内不再显示。选区外保留原始清晰度，同页可独立编辑的顶层文字和矢量线条仍可单独编辑。某些嵌套内容看起来像文字或线条，但无法作为页面对象单独编辑，会随它所在的嵌套绘制内容一起裁去选区内的部分。复杂结构或选区中缺少可擦除的内容时，软件会提示。

页面局部擦除通过 PDF 裁剪保留原始图片数据。涉及敏感信息时，请使用专门的永久脱敏工具，再检查导出的文件。

## 图片像素修复与对象删除

- 需要修复图片底色或把笔迹擦成透明时，打开「编辑原文 → 对象图层」，筛选并选中图片，点击「图片裁切 / 橡皮擦」。对支持的图片按原始像素尺寸处理。均匀背景、纸色和轻微渐变更适合底色修复。同一张图需要补色和圈选擦除时，可以先补色，再圈选擦除。
- 要删除一条完整线条、一段可编辑文字或一个完整图片对象，可在「编辑原文」里选中对象后删除。一次选择会对应一个 PDF 对象。
- 如果旧版已将整个页面保存成图像，从转换前的原 PDF 重新编辑可以保留原有文字和矢量结构。

## 文字修改与字体

使用「文本框」在页面上拖出文字框后输入。选中已添加的文字可直接修改，短暂停顿后自动应用；离开编辑区域或按 `Ctrl+Enter` 也可提交。「编辑原文」里的单对象文字修改在离开输入区域或按 `Ctrl+Enter` 后校验并应用。

新文字优先使用已安装的 **Century Gothic**。原文编辑和文字行编辑默认勾选更换为可嵌入的本机字体，单纯选中对象时原文字体仍保留。修改前可以取消勾选，或选择允许嵌入且覆盖所需字形的本机字体。Century Gothic 不附带在安装包中。

保存 `.jvp` 可在此应用继续编辑工作区里的新增文字。另存 PDF 副本时，新增文字以图像写入，对支持的原文对象修改可保留为可搜索文字。
